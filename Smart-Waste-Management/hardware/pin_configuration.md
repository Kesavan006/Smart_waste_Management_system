# Pin Configuration

| Device | Signal | ESP32 GPIO |
|---|---|---:|
| HC-SR04 | TRIG | GPIO 5 |
| HC-SR04 | ECHO | GPIO 18 |
| SSD1306 | SDA | GPIO 21 |
| SSD1306 | SCL | GPIO 22 |
| Buzzer | Signal | GPIO 14 |
| Green LED | Anode | GPIO 25 |
| Yellow LED | Anode | GPIO 26 |
| Red LED | Anode | GPIO 27 |
| LEDs / Buzzer | Ground | ESP32 GND |
| HC-SR04 | VCC | ESP32 5V |
| HC-SR04 | GND | ESP32 GND |
| SSD1306 | VCC | ESP32 3V3 |
