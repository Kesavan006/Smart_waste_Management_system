# Wokwi Simulation

The simulation uses the supplied ESP32 DevKit, HC-SR04, SSD1306 OLED, three LEDs and buzzer configuration.

Open `diagram.json` in a Wokwi ESP32 project and use the source file from `src/`.

## Connections

- HC-SR04 TRIG → GPIO 5
- HC-SR04 ECHO → GPIO 18
- OLED SDA → GPIO 21
- OLED SCL → GPIO 22
- Buzzer → GPIO 14
- Green LED → GPIO 25
- Yellow LED → GPIO 26
- Red LED → GPIO 27
